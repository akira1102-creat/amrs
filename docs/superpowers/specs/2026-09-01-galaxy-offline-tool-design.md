# Galaxy Log 完全離線工具設計

## 目標

新增一個免安裝、免管理員權限、完全離線的 Windows EXE，讓永久禁網的 Surface 可以讀取由 AMRS 匯出的 Galaxy CSV，在現場搜尋 SN、記錄取 Log 結果，再匯出 CSV 帶回有網絡的 AMRS 電腦同步至雲端。

工具不會連接網絡、不會讀取 Token、不會呼叫 AMRS Worker，也不會保存原始清單或操作歷史到雲端。

## 使用流程

1. 有網絡的 AMRS 電腦按「下載雲端資料」，取得最新 Google Sheet 資料。
2. AMRS 按「匯出 CSV」，產生標準 CSV。
3. 禁網 Surface 的 Galaxy Log Offline EXE 按「匯入 CSV」。
4. 現場以完整 SN 或末 4 位搜尋，按「已取 Log」或「沒有當天 Log」。
5. EXE 按「匯出 CSV」，將更新後檔案帶回公司。
6. AMRS 匯入 CSV，檢查後按「同步至雲端」。

## CSV 契約

輸出欄位固定為：

`SN, SN末4位, 指定 Log 日期, 取 Log 日期, 狀態`

不輸出備註欄。CSV 使用 UTF-8 BOM、逗號分隔、RFC 4180 引號規則及 CRLF 換行。

`SN` 保留完整機身號碼；`SN末4位` 由完整 SN 推導但保留來源值；兩者都會匯出。

「已取 Log」的 `取 Log 日期` 為按鈕當日，狀態為 `已取`。 「沒有當天 Log」的 `取 Log 日期` 同樣為按鈕當日，狀態為 `沒有當天 Log`；Sheet 儲存格格式為 `YYYY-MM-DD 已檢查無log`。讀取時同時兼容舊有 `沒有當天 Log` 標記及新格式。

## 匯入及較新資料規則

每個資料列以 `SN + 指定 Log 日期` 作為穩定識別；同一 SN、同一指定日期的重覆列以額外出現次序保持獨立。

CSV 會讀取檔案的最後修改時間作為匯入版本時間，並把它與本機目前清單的匯入版本比較：

- 匯入 CSV 較新：完整以匯入清單取代本機清單，包含狀態及取 Log 日期。
- 匯入 CSV 相同或較舊：不覆蓋本機較新的清單，介面顯示「本機資料較新」。
- 首次匯入：直接載入 CSV。
- 檔案時間不可取得時：以匯入動作時間作版本時間，並顯示提示。

覆蓋是整份清單層級，不會逐列混合新舊檔案，避免現場工具產生半新半舊資料。

## 離線介面

使用 C# WinForms 製作，深色卡片介面對齊 AMRS Galaxy Log：

- `匯入 CSV`
- `匯出 CSV`
- 搜尋完整 SN／末 4 位
- 狀態篩選：未取、需跟進、已取、沒有當天 Log、全部
- 每張卡顯示末 4 位（主標題）、完整 SN（細字）、指定日期、狀態及檢查／取 Log 日期
- 現場操作按鈕：`✓ 已取 Log`、`沒有當天 Log`；已完成的列可 `改回未取`
- 匯入較新檔案時顯示覆蓋確認及新舊日期；較舊檔案不會覆蓋本機資料

工具只在記憶體中處理清單，使用者需要按「匯出 CSV」才會產生檔案；不保存原始 CSV、SN 歷史或網絡設定。

## AMRS 配合修改

- Galaxy 頁面的 `同步雲端` 改為 `同步至雲端`。
- `匯入雲端` 改為 `下載雲端資料`。
- AMRS 匯出及匯入均使用上述五欄 CSV 契約。
- 匯入 CSV 時以 CSV 的匯入版本時間比較本機清單；較新的匯入檔完整覆蓋本機資料。
- 雲端下載始終視為最新雲端版本，下載後取代本機清單。

## 打包及驗證

- 以 .NET self-contained single-file、Windows x64、無 Console 視窗方式打包。
- 產物放在獨立 release 資料夾，內含 EXE 及簡短使用說明，不包含測試資料、Token、個人路徑或客戶資料。
- 使用合成 CSV 測試：UTF-8 BOM、引號逗號、完整 SN、合併儲存格匯出結果、較新／較舊匯入、重覆 SN 日期、已取、沒有當天 Log、改回未取。
- 驗證 EXE 可在網絡停用時啟動、匯入、搜尋、修改、匯出，不要求提升權限，且不產生網絡請求。
- AMRS 前端修改會同步更新 Service Worker cache 版本並在實際線上頁面確認文字及 CSV 行為。
