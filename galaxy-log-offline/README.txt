Galaxy 取 Log Offline

用途
----
這是一個完全離線的 Windows 工具，沒有同步雲端、Token、Google Sheet 或網絡功能。

使用流程
--------
1. 在有網絡的 AMRS 電腦按「下載雲端資料」，再按「匯出 CSV」。
2. 將 CSV 帶到離線 Surface，開啟 GalaxyLogOffline.exe，按「匯入 CSV」。
3. 搜尋 SN 末四位，按「已取 Log」或「沒有當天 Log」。按鈕日期會記錄當日。
4. 按「匯出 CSV」，將輸出的檔案帶回 AMRS 電腦匯入，再按「同步至雲端」。

安全及資料規則
--------------
- 全部資料只保存在本機使用者資料夾，程式不會連線。
- 匯入 CSV 只有在檔案修改時間較新時才會完整取代本機清單；舊檔或相同時間會保留本機資料。
- CSV 欄位固定為：SN、SN末4位、指定 Log 日期、取 Log 日期、狀態。
